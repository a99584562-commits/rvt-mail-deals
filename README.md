# Почта → Сделки · РВТ (демо)

Демо-прототип админки для автоматического создания сделок в Битрикс24 из входящих писем
(по ТЗ «Формирование сделок на основании писем из почты»).

Что показывает:

- **Поток** — журнал обработанных писем: созданные сделки, пропуски, дубликаты, статистика.
- **Симулятор** — живой прогон письма через конвейер: ключевые слова → правило отправителя →
  проверка дубликатов → сделка в воронке «Продажи РВТ» (стадия «Новая»).
- **Слова** — редактируемый словарь из ~40 терминов ТЗ (фразы — по вхождению, аббревиатуры — по слову).
- **Правила** — настройки маппинга полей и критериев дубликатов под каждого отправителя.

Данные смоделированы, портал Битрикс24 не подключён. Настройки (словарь, тумблеры правил)
сохраняются в localStorage.

## Стек

Vite + React + TypeScript + Tailwind. Деплой — GitHub Pages (Actions).

```bash
npm install
npm run dev    # http://localhost:5196
npm run build
```
